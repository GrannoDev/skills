# UI bug report

Order confirmed findings by severity and flow. Include observed intermittent failures with attempt counts; exclude unconfirmed issues from totals.

```markdown
# Break UI: <app>
Target: <environment, scope, angles, bug counts by severity>

## <severity>: <failure>
Where: <screen/control>
Impact: <consequence>
Reproduce: <role, starting state, exact steps, successes/attempts>
Expected: <behavior and source>
Actual: <observed result>
Evidence: <captured screenshot/log links>

## Not reproduced
<Issue, attempts, uncertainty; None if empty>
## Coverage
<Exercised flows/checks; excluded or blocked checks and reasons>
```

With zero bugs, omit finding entries and retain coverage. Link only existing evidence.
